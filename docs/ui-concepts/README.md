# UI concept images

These three concept screens illustrate the MVP's proposed visual direction. They are generated mockups, not working application screens. All example values, organizations, relationships, excerpts, source labels, and map geometry are illustrative.

| Image | Purpose |
| --- | --- |
| [County overview](01-county-overview.png) | Orient around geography, economic structure, coverage, and evidence gaps. |
| [Evidence explorer](02-evidence-explorer.png) | Inspect a function, its relationships, and the evidence behind a claim. |
| [Private research desk](03-research-desk.png) | Compare candidate responsibilities and examine explicit scenario assumptions. |

Design direction: warm neutral surfaces, deep green navigation, restrained sage charts, amber evidence gaps, readable tables, and prominent provenance. Source dates, limitations, and unknowns are part of the main workflow. Each map should have an equivalent table in implementation. Coverage should use explained categories; conceptual bars do not imply measured completeness. The small relationship diagram is an optional visual exploration beyond the MVP's required linked profiles.

Generation method: built-in image_gen tool. The exact prompts are preserved below. Treat rendered text and chart geometry as design sketches; implementation must use validated data and deterministic calculations. The example candidates are design content, not selected business recommendations.
